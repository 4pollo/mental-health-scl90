## 图标替代方案

为了减少对外部图像资源的依赖，本小程序使用Unicode字符作为图标：
- 🧠 (U+1F9E0) - 大脑图标，用于首页
- 📊 (U+1F4CA) - 图表图标，用于结果页
- ✅ (U+2705) - 勾选图标，用于提交按钮
- 🔄 (U+1F504) - 循环箭头图标，用于重新测试按钮
- ⬅️ (U+2B05) - 左箭头图标，用于上一题按钮
- ➡️ (U+27A1) - 右箭头图标，用于下一题按钮
- 📋 (U+1F4CB) - 剪贴板图标，用于测评介绍
- 💡 (U+1F4A1) - 灯泡图标，用于测评说明

## 配色方案

### 当前配色方案（黑白灰）
本小程序当前采用简洁的黑白灰配色方案，具有以下特点：
- 背景色：#ffffff (白色)、#f5f5f5 (浅灰色)、#e0e0e0 (中等浅灰色)、#cccccc (中等灰色)
- 文字色：#000000 (黑色)、#666666 (中等灰色)
- 边框色：#000000 (黑色)、#cccccc (中等灰色)、#e0e0e0 (中等浅灰色)、#f5f5f5 (浅灰色)
- 悬停状态：统一使用黑色

### 配色方案扩展
本小程序支持多种配色方案，可通过以下方式切换：
1. 修改 `utils/colorConfig.js` 文件中的 `currentTheme` 属性
2. 使用 `themeManager.js` 中的 `switchTheme()` 方法动态切换

目前支持的配色方案：
- `blackWhiteGray` - 黑白灰配色（默认）
- `green` - 绿色配色（原始设计）

### 配色方案配置文件
配色方案配置在 `utils/colorConfig.js` 文件中，包含：
- 背景色定义
- 文字色定义
- 边框色定义
- 悬停状态颜色定义
- 特殊颜色定义（成功、警告、危险等）

## 字体大小规范

- 大标题：42rpx

- 小标题：32rpx
- 正文：28rpx
- 辅助文字：26rpx
- 图标：30-35rpx

## 主题管理

本小程序使用以下文件进行主题管理：
- `utils/colorConfig.js` - 颜色配置文件，定义所有配色方案
- `utils/themeManager.js` - 主题管理器，提供切换和获取主题颜色的方法
- `utils/themeHelper.js` - 主题助手函数，提供便捷的WXSS类名获取方法

通过这些文件，可以轻松地添加新的配色方案或切换现有方案。
